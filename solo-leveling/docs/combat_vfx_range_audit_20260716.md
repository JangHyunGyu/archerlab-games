# Combat VFX hit-range audit — 2026-07-16

## 기준

- 방향형 근접 공격은 캐릭터에서 실제 판정 반경의 90% 지점까지 불투명 이펙트가 닿게 한다. 남은 10%는 적 몸체 반경과 가장자리 안티앨리어싱 여유다.
- 직선 관통은 실제 선분 길이의 96%를 이미지가 덮는다.
- 지점 충돌과 자기중심 오라는 PNG 전체 512px가 아니라 `alpha >= 12`인 실제 가시 영역의 가로·세로를 각각 판정 지름에 맞춘다.
- 투사체는 이동 중심이 설정 사거리 전체를 주행한다. 투사체 굵기는 직접 충돌 또는 폭발 지름과 별도로 대조한다.
- 가시 영역 수치는 `install_higgsfield_character_vfx_20260716.py`가 `CombatVfxMetrics.js`로 재생성한다.

## 이름과 레이어 수정

- 검사 기본공격은 런타임이 `swordSlash`이므로 `빛가름 찌르기`에서 `빛가름 검격`으로 변경했다. 설명도 찌르기에서 베기로 맞췄다.
- `섬광 찌르기`는 생성 이미지 위에 절차형 10px/4px/1.5px 직선을 덧그리던 설정을 제거했다. 이제 `light_lance_pierce` 6프레임만 표시된다.
- 지점 공격의 확장 시간은 각 `impactDelay`와 같게 맞춰, 실제 피해가 들어가는 프레임에 이미지가 판정 지름에 도달한다. 즉시 판정되는 `성광 압박` 오라는 첫 프레임부터 전체 반경을 사용한다.

## 검증

`tests/combat-vfx-coverage.test.cjs`가 25개 키 전체의 범위 규칙과 검사 이름, 섬광 찌르기 이미지 단독 설정을 검사한다. 정적 검증은 가시 영역 메트릭 누락과 런타임 자동 맞춤 연결도 차단한다.
