# 젤리팡 사운드 정의

젤리팡 MP3 파일은 아래 기준으로 제작해서 `jelly-pang-2048/assets/sounds/` 폴더에 넣는다.

현재 게임 코드에서 필요한 기본 사운드는 5개다.

| 파일명 | 재생 시점 | 길이 | 느낌 |
| --- | --- | --- | --- |
| `jelly-slide.mp3` | 타일이 이동만 하고 합쳐지지 않았을 때 | 0.05-0.12초 | 짧고 가벼운 젤리 미끄러짐. 너무 날카롭지 않게. |
| `jelly-merge.mp3` | 같은 젤리 두 개가 합쳐질 때 | 0.12-0.25초 | 통통 튀는 상승음. 보상감이 있어야 함. |
| `jelly-bump.mp3` | 이동할 수 없는 방향으로 입력했을 때 | 0.06-0.14초 | 낮고 둥근 막힘 소리. 실패음이지만 거슬리지 않게. |
| `jelly-win.mp3` | 2048 젤리를 처음 만들었을 때 | 0.45-0.9초 | 밝은 성공 팡파르. 짧게 축하하는 느낌. |
| `jelly-gameover.mp3` | 더 이상 움직일 수 없어 게임이 끝났을 때 | 0.35-0.8초 | 아쉽지만 귀엽게 내려가는 소리. 너무 우울하지 않게. |

## 제작 규칙

- 포맷: MP3
- 샘플레이트: 44.1kHz 또는 48kHz
- 권장 음량: 피크 -6dB 이하
- 앞뒤 무음: 가능하면 20ms 이하
- 반복 재생: 사용하지 않음
- 전체 톤: 말랑한 젤리, 과일, 버블, 캐주얼 퍼즐 느낌
- 피해야 할 톤: 금속성 클릭, 긴 알림음, 공포/경고음처럼 강한 소리

## 코드 매핑

현재 `jelly-pang-2048/js/main.js`의 `playSound(type)`에서 쓰는 타입은 아래와 같다.

| 코드 타입 | MP3 파일 |
| --- | --- |
| `slide` | `jelly-slide.mp3` |
| `merge` | `jelly-merge.mp3` |
| `bump` | `jelly-bump.mp3` |
| `win` | `jelly-win.mp3` |
| `gameover` | `jelly-gameover.mp3` |

MP3 파일을 넣은 뒤에는 기존 WebAudio 합성음을 위 파일 재생 방식으로 교체하면 된다.

## 선택 사운드

아래는 지금 코드에서 필수는 아니지만, 나중에 화면 연출을 더 넣을 때 사용할 수 있다.

| 파일명 | 재생 시점 | 길이 | 느낌 |
| --- | --- | --- | --- |
| `jelly-start.mp3` | 시작 화면에서 게임 시작 버튼을 눌렀을 때 | 0.15-0.35초 | 밝고 짧은 출발음 |
| `jelly-rank-open.mp3` | 명예의 전당을 열 때 | 0.12-0.28초 | 반짝이는 오픈음 |
| `jelly-rank-submit.mp3` | 랭킹 등록 성공 시 | 0.25-0.55초 | 작은 축하음 |

## 기존 게임 사운드 후보

다른 게임에서 가져다 쓸 경우에는 `jewelria`의 MP3 사운드가 젤리팡 톤에 가장 잘 맞아 보인다. `solo-leveling`과 `school-zombie-defense`는 전투/좀비 톤이 강해서 젤리팡 기본 효과음으로는 덜 어울린다.

| 젤리팡 용도 | 후보 파일 | 비고 |
| --- | --- | --- |
| `jelly-slide.mp3` | `jewelria/assets/sounds/sfx/swap.mp3` | 타일 이동음 후보 |
| `jelly-merge.mp3` | `jewelria/assets/sounds/sfx/match.mp3` | 기본 합치기 후보 |
| `jelly-merge.mp3` 또는 콤보용 | `jewelria/assets/sounds/sfx/combo.mp3` | 더 화려한 합치기 후보 |
| `jelly-win.mp3` | `jewelria/assets/sounds/sfx/special.mp3` | 2048 달성 축하음 후보 |
| `jelly-bump.mp3` | `jewelria/assets/sounds/sfx/invalid.mp3` | 막힌 입력 후보 |
| `jelly-gameover.mp3` | `jewelria/assets/sounds/sfx/fail.mp3` | 게임오버 후보 |
| `jelly-start.mp3` | `jewelria/assets/sounds/sfx/button.mp3` | 시작 버튼 후보 |
| `jelly-rank-open.mp3` | `jewelria/assets/sounds/sfx/clear.mp3` | 명예의 전당 오픈 후보 |

`blockpang` 쪽은 `sparkle.wav`, `combo_hit.wav`, `combo_escalate.wav`, `clear_single.wav`, `clear_double.wav`가 후보지만 WAV라서 MP3가 필요하면 변환해서 쓰는 편이 좋다.
