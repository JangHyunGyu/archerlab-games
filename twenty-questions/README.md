# 시맨틀 (Korean Semantle) 구현

한국어 `/twenty-questions/`, 영어 `/twenty-questions/index-en`에서 제공하는 6시간 동기화 한국어 단어 유사도 추리 게임.

## 핵심 동작

- FastText 사전 학습 한국어 300차원 벡터(`cc.ko.300.vec.gz`) + 한국어 Hunspell 사전(`ko.dic`) + Wiktionary `Korean_5800` 빈도 목록 기반
- 양자화 벡터(`hot-pack.bin`, `cold-*.bin`)와 정답별 상위 1,000개 유사 단어 테이블(`secrets-top1k.bin`)을 Cloudflare R2(`archerlab-r2/semantle-{ko,en}/v4/`)에 저장하고, Worker가 Range 읽기로 런타임 유사도 계산 (외부 AI 호출 없음)
- **v4 팩: 추측 가능 어휘 = 순위 어휘**: v2는 사전 기반 부분집합(ko 13.6만 단어)에서만 상위 1,000개를 뽑으면서 FastText 전체(150만 단어)를 추측으로 받았다. 그래서 부분집합 밖 단어(예: `지구과학`)는 1,000위 유사도를 넘어도 `1,000위 밖`으로 표시됐다. v4는 v2 순위 어휘에 사전이 놓친 실제 단어를 더한 어휘만 추측으로 받고, 그 어휘 전체에서 상위 1,000개를 계산한다. 그래서 순위가 항상 유사도 순서를 따른다.
  - ko +27,186(총 162,945): 자주 쓰이는 명사·복합명사(`지구과학`, `혼밥`)와 kiwi 사전에 있는 희귀 단일 명사(`마라탕`, `메타버스`). en +3,459(총 138,816): Hunspell 접사 형태(`smartphones`)와 자주 쓰이는 신조어·브랜드(`youtube`, `blogpost`)
  - 거절(사전에 없는 단어): 조사·어미·활용형(`과학을`, `다정함`, `맛있는`), 오타(`writting`), 희귀 복합어(`제철과일`), 희귀 인명·기관·시설·지명(`검단고등학교`, `반송동`), kiwi가 모르는 단어(`에어프라이어`, `민트초코`), 도박·성인 스팸, 비속어·혐오 표현, 숙박 사이트 템플릿 조합(`요금가격`). 희귀 복합어를 넣으면 상위 100위 안에 정답이 포함된 단어 비율이 1.6%에서 3.6%로 늘었고, 희귀 학교 이름 등은 일부 정답의 상위 1,000개를 수백 개씩 채워서 제외했다
  - 빌드: `twenty-questions/tools/build-semantle-ranked-pack.py --pack v4` (입력: 배포된 v2 팩 + v2 사전 소스. 입력 해시와 라이브러리 버전은 `manifest.json`에 기록. 정답 목록·순서는 v2와 같아서 라운드별 정답은 바뀌지 않는다)
  - v3는 같은 방식의 첫 빌드였지만 스팸·비속어가 섞여서, 어떤 라운드에도 쓰이기 전에 v4로 대체했다
- 라운드는 생성할 때 쓴 팩을 `sm_rounds.data_pack`에 기록한다. 이 컬럼이 생기기 전에 만든 라운드(`NULL`)는 v2 팩으로 끝까지 진행하고, 이후 생성되는 라운드부터 v4 팩을 쓴다. 이긴 게임은 지난 라운드의 상위 1,000개를 다시 열 수 있으므로, 기록된 라운드가 가리키는 팩(`semantle-*/v2/`, `v3/`, `v4/`)은 R2에서 지우지 않는다
- 팩 버전을 바꾸는 배포나 롤백은 라운드 경계(KST 00·06·12·18시) 앞뒤 10분을 피한다. 새 팩으로 생성된 라운드를 옛 코드가 처리하면, 그 라운드에서는 옛 팩 순위와 새 팩 기준값이 섞인다. 코드가 모르는 팩 값은 현재 팩으로 처리한다
- game-api Workers Builds 트리거는 `path_includes`에 `server/**`가 없다. 그래서 시맨틀 서버만 바꾼 푸시는 자동 배포되지 않으니, 트리거를 수동 실행하거나 경로를 추가해야 한다
- **6시간 KST 동기화 라운드 & 강제 초기화**: 매일 한국시간 `00:00 · 06:00 · 12:00 · 18:00` 정각에 전체 플레이어가 동일한 새 단어로 전환되고 이전 추측 기록·초안이 자동 초기화됨 (`06:00:00 -> 00:00:00` 서버 기준 역카운트다운)
- **포기하기 없음 & 직전 라운드 정답 공개**: 진행 중 정답 유출·부계정 어뷰징을 막기 위해 포기하기를 제거했고, 6시간 정각 전환 후 직전 라운드 정답과 상위 1,000개 단어를 상단·로비에서 확인 가능
- **현재 정답자 표기 & 라운드 오픈 기준 역대 랭킹**: 게임 화면에 현재 라운드 정답자(검증 완료 기준)를 실시간 표시하며, 역대 명예의 전당은 라운드 오픈 정각부터 정답까지 걸린 시간(`solvedMs = 정답 시각 - 라운드 시작 시각`, 2회 이상·1.5초 이상)으로 등록
- 플레이어별 요청은 `TwentyQuestionsRoom` Durable Object가 직렬 처리하며, `sm_*` D1 테이블(`sm_rounds` 포함)에 라운드·상태·기록·로그 저장
