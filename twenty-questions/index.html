자주 묻는 질문

시맨틀은 어떻게 푸나요?

단어를 입력하면 정답과의 의미 유사도(-100 ~ +100점)를 알려줘요. 점수가 높고 상위 1,000위 안에 드는 단어를 따라 좁혀 가면 정답에 닿을 수 있어요.

시간과 명예의 전당 랭킹은 어떻게 기록되나요?

새 문제를 여는 순간 서버 시계 기준으로 시간이 올라가기 시작하며, 다른 창으로 이동하거나 앱을 닫아도 시간은 멈추지 않고 계속 흐릅니다. 2회 이상의 정상 추리로 가장 빠르게 정답을 맞힌 기록이 명예의 전당에 자동 등록돼요.

어떤 단어가 정답이 되나요? 왜 반대말도 점수가 높나요?

정답은 한국어 빈도 어휘 중 2글자 이상 기본형(명사·동사·형용사·부사)에서 뽑힙니다. ‘사랑’과 ‘증오’처럼 반대되는 말이라도 같은 문맥에 자주 나오면 유사도가 높을 수 있고, ‘밤’처럼 뜻이 여러 개인 단어는 자주 쓰이는 문맥 쪽 점수가 높게 나와요.

하루에 한 번만 할 수 있나요?

아니요. 하루 횟수 제한 없이 원할 때마다 새 문제를 계속 풀 수 있어요. 정답을 맞히거나 포기한 뒤 상위 1,000개 단어를 살펴보고 바로 다음 문제로 넘어가 보세요.
