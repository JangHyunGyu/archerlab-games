# 주차장 탈출 사운드 정의

주차장 탈출게임의 효과음은 현재 `parking-escape/js/SoundManager.js`에서 Tone.js로 실시간 합성한다.
별도 MP3 파일 없이도 동작하지만, 더 실제 같은 녹음/제작 샘플로 교체하려면 아래 기준으로 `parking-escape/assets/sounds/` 폴더에 넣는다.

## 기본 방향

- 톤: 실내 주차장, 아스팔트 바닥, 짧은 차량 이동, 금속성 충돌, 주차 센서.
- 전체 볼륨: 게임 BGM이 없으므로 효과음이 선명하게 들리되, 피크는 -1dB 이하.
- 길이: 대부분 0.05-0.45초. 출구 탈출/클리어만 0.5-1.0초 허용.
- 앞뒤 무음: 가능하면 20ms 이하.
- 반복 재생: 루프형이 아니라 원샷 효과음.
- 피해야 할 것: 너무 만화적인 삑삑음, 공포/전투 톤, 폭발음, 긴 엔진 아이들 루프.

## 현재 코드 매핑

현재는 MP3 파일 대신 `ParkingSoundManager.play(type, intensity)`가 아래 타입을 Tone.js 레이어로 합성한다.

| 코드 타입 | 현재 재생 시점 | 샘플 교체 시 권장 파일 |
| --- | --- | --- |
| `start` | 게임 시작/레벨 진입 | `parking-start.mp3` |
| `dragStart` | 차량을 잡을 때 | `parking-drag-pick.mp3` |
| `move` | 일반 차량 이동 | `parking-car-move.mp3` |
| `targetMove` | 목표 차량 이동 | `parking-target-move.mp3` |
| `blocked` | 이동 불가/막힘 | `parking-blocked.mp3` |
| `exit` | 목표 차량 출구 탈출 | `parking-exit.mp3` |
| `win` | 클리어 성공 강조 | `parking-clear.mp3` |
| `timer` | 남은 시간 5초 이하 경고 | `parking-time-warning.mp3` |
| `timeout` | 시간 종료 | `parking-timeout.mp3` |
| `button` | 일반 버튼 | `parking-button.mp3` |
| `rank` | 랭킹 열기 | `parking-rank-open.mp3` |
| `submit` | 랭킹 등록 성공 | `parking-rank-submit.mp3` |
| `hint` | 힌트용 예비 타입 | `parking-rank-open.mp3` 또는 별도 `parking-hint.mp3` |

## 현재 Tone.js 레이어 설계

`SoundManager.js`는 실제 차량 느낌을 내기 위해 한 효과음 안에서 여러 레이어를 짧게 겹친다.

| 레이어 | 역할 |
| --- | --- |
| `body` | 차체 저역 떨림, 묵직한 덜컹임 |
| `engine` | 일반 엔진 이동음 |
| `rev` | 가속/탈출 시 엔진 피치 상승 |
| `gear` | 차량 선택, 버튼, 기어 클릭 |
| `roll` | 바퀴가 바닥을 구르는 저역 노이즈 |
| `tire` | 아스팔트 타이어 마찰 |
| `skid` | 급한 이동/막힘에서 나는 고역 스침 |
| `air` | 출구 통과, UI 오픈의 공기감 |
| `rumble` | 실패/충돌의 짧은 저역 흔들림 |
| `impact` | 막힘과 타임업의 타격음 |
| `metal` | 차체/게이트의 짧은 금속 잔향 |
| `sensor` | 남은 시간 경고 비프 |
| `bell`, `pad` | 랭킹/성공 UI 알림 |
| `reverb`, `delay`, `comp`, `limiter` | 실내 주차장 공간감, 출력 정리, 피크 보호 |

## 샘플로 교체할 때의 구현 메모

- MP3 파일을 추가하면 `SoundManager.js`에서 Tone.js 합성 대신 `Tone.Player` 또는 WebAudio `AudioBufferSourceNode`로 교체한다.
- 짧은 효과음은 첫 사용자 입력 후 미리 로드한다.
- `move`, `targetMove`는 같은 파일을 재생하더라도 `playbackRate`를 0.94-1.08 사이로 살짝 바꾸면 반복감이 줄어든다.
- `blocked`, `timer`는 연속 입력이 많으므로 최소 재생 간격을 유지한다.
- 모바일 브라우저는 첫 터치 전 오디오가 막히므로, 현재처럼 `pointerdown`에서 `Tone.start()`를 호출해야 한다.

현재 레포 안에서 임시 후보로 쓸 수 있는 파일은 아래 정도다. 다만 주차장 탈출에는 실제 차량/주차장 질감이 더 잘 맞으므로, 최종본은 별도 제작을 권장한다.

## 현재 적용 상태

- `parking-escape/assets/sounds/parking-start.mp3`를 START 시동음으로 사용한다. 원본은 `dragon-studio-car-engine-372477.mp3`이다.
- `parking-escape/assets/sounds/parking-target-move.mp3`를 목표 차량 이동음으로 사용한다. 원본은 `tanweraman-car-pass-by-337871.mp3`이다.
- `jewelria/assets/sounds/sfx/`에서 버튼, 막힘, 클리어, 타임아웃, 랭킹 효과음을 가져와 주차장용 파일명으로 복사했다.
- 샘플은 트림하지 않고 전체 길이로 재생한다. 재생 볼륨은 `SoundManager.js`의 `SAMPLE_SETTINGS`에서 맞춘다.
- 샘플이 아직 로드되지 않았거나 파일을 사용할 수 없으면 `parking-escape/js/SoundManager.js`에서 Tone.js 레이어형 효과음으로 fallback한다.
- 사운드 ON/OFF 토글은 `parking-escape/index.html`의 `#sound-toggle-btn`과 `main.js`의 `toggleSound()`에 연결되어 있다.
- 캐시 방지를 위해 `index.html`에서 `SoundManager.js?v=20260627-uncut`를 사용한다.
