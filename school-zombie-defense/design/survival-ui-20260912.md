# Survival UI art direction

The UI uses worn painted metal, charcoal and olive surfaces, chalk-colored live lettering, and faded ochre primary actions. Background and character artwork remain the visual focus. Cyan emission, metallic gold frames, digital scan lines and circular inventory badges have been removed from the interface.

## Production assets

Generated with the built-in image generation tool. PNG files preserve the original generated artwork. WebP copies preserve the dimensions and alpha and are used by supported browsers.

| Asset under `assets/images/` | Purpose |
| --- | --- |
| `ui-survival-button.png` / `.webp` | Secondary actions and combat controls |
| `ui-survival-primary.png` / `.webp` | Sortie, resume, affordable upgrades and record submission |
| `ui-survival-panel.png` / `.webp` | HUD, menus, cards, lists, notices and HTML dialogs |
| `ui-survival-equipment.png` / `.webp` | Sixteen unframed equipment illustrations for inventory and skill choices |

`js/ui-surfaces.js` renders the first three images in nine slices, preserving the corner sizes across button and panel dimensions. Rendered surfaces are cached at twice the logical resolution. Text remains live, independently rendered at twice the logical resolution. CSS border images provide the corresponding treatment for HTML dialogs. The existing portrait game aspect ratio, device safe areas, keyboard entry behavior, touch hit regions and reduced-motion handling are preserved.

The inventory atlas maps existing skill IDs to equipment illustrations without changing upgrades, prices, combat effects, character animation or save data. Shop metadata retains the original descriptions; the card omits the repeated weapon-category subtitle already given by the selected character heading.

## Generation prompts

### Secondary button

Use case: stylized-concept. Create a production-ready raster UI asset for a premium post-apocalyptic survival defense game set inside a ruined Korean school. This is one single EMPTY rectangular button face, not a UI mockup or sheet, no text or symbols. Landscape 3:1 canvas, 1536 by 512 if possible. The plate fills the entire canvas edge-to-edge so its outer boundary is exactly the image boundary, with no backdrop, margins, perspective, tilt, or cast shadow outside it. Orthographic front-on view. Material: authentic salvaged steel painted deep charcoal olive-black, roughly #252923, with wonderfully detailed matte enamel, fine dusty grain, restrained rubbed edges, tiny localized oxide wear in warm brown and subtly worn thin inset lip. Expensive art-directed survival game quality; tactile, understated, cinematic and realistic, hand-worn imperfections rather than random noise. Center 85% is quiet dark slightly mottled enamel, totally empty and clean enough for crisp live Korean text. Rim only 10-18px thick at this resolution, low contrast: dark worn paint not shiny bare metal. Barely rounded industrial corners (4px), largely rectangular. All edge detail contained in outermost 30px so the center and edge strips can stretch as a nine-slice asset for widths 100 to 450 and heights 40 to 90. No screws or rivets in the center; preferably no bolts at all. Avoid: cyan, blue, neon, glow, chrome, gold trim, futuristic bevels, polygon cut corners, sci-fi, cyberpunk, fantasy, warning stripes, decals, words, letters, logos, labels, icons, arrows, blood splashes, exaggerated rust, gradients resembling glossy UI. The overall read must be a restrained physical piece of worn charcoal-painted metal, not a decorative fantasy frame.

### Equipment atlas

Use case: stylized-concept. Create ONE cohesive production-ready 4 by 4 game inventory icon atlas, square 1536x1536, exactly sixteen equal square cells, perfectly regular grid. Transparent background with real alpha, no visible grid lines and no cell borders. Each object fully contained and centered in its own 384x384 cell with 60px clear padding. Premium post-apocalyptic zombie survival game set in a ruined modern school. Art style: highly crafted semi-realistic hand-painted inventory illustrations, tactile weathered metal and worn materials, crisp silhouettes readable at 48px, cinematic warm neutral highlights, charcoal, muted olive, worn brass, restrained rust. No typography anywhere, no letters or numbers, no circular badges, no decorative frames, no halos, no energy glow, no gold rings, no sci-fi elements. Sixteen subjects in this exact order reading row-major: row 1: worn black semiautomatic pistol; three brass pistol cartridges; a steel crossbow bolt with feather fletching; worn black assault rifle. Row 2: olive military rocket warhead; scratched rifle scope; brown glass molotov bottle with short small flame; battered pale blue coolant canister with frost. Row 3: old blocky lead-acid battery with simple terminals; wound copper induction coil; compact improvised gun turret; tangled short length of barbed wire. Row 4: well-used steel wrench; square salvaged steel armor plate; off-white first aid pouch with small muted red cross; detached black rifle magazine. Exactly one subject per cell, large and cleanly separated. No overlapping cells, no extra objects, no text, no labels. Cohesive lighting, realistic materials, sober survival-game visual direction. Background must be genuinely transparent.
